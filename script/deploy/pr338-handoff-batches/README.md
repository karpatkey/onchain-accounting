`0x8b884f80B3B839F52b6cE168f133e7a5D1f0A537` **on that chain** (Safe → Apps → Transaction Builder → import the file).
Generated by `script/deploy/11_DeployTimelockController.s.sol`; each was checked against independently rebuilt
calldata and dry-run on a fork as the Council.

Every file has the same 4 calls to the NAV proxy `0x54EaD2A1dB7456cA917675Ea8908ec8A997c6214`, **in this order —
do not reorder or split**:

1. `grantRole(DEFAULT_ADMIN_ROLE, 0xAB92EA75D07792915eB1f29259354866B880dFC2)` — the timelock
2. `grantRole(MANAGER, 0xAB92EA75D07792915eB1f29259354866B880dFC2)`
3. `revokeRole(MANAGER, 0xAa5A7C7Ea51F276301f881F9CCB501a1dFeF4F72)` — the deployer EOA
4. `revokeRole(DEFAULT_ADMIN_ROLE, 0xAa5A7C7Ea51F276301f881F9CCB501a1dFeF4F72)`
